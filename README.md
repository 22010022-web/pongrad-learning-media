# ระบบส่งสื่อการจัดการเรียนรู้ โรงเรียนวัดโป่งแรด (ปคุณวิทยาคาร)
**Learning Media Submission System**

ระบบเว็บแอปพลิเคชันสำหรับติดตามและส่งผลงานสื่อการจัดการเรียนรู้ของครูผู้สอน โรงเรียนวัดโป่งแรด (ปคุณวิทยาคาร) สำนักงานเขตพื้นที่การศึกษาประถมศึกษาจันทบุรี เขต 1

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **Dashboard สำหรับผู้บริหาร (ผู้อำนวยการ):**
   - ตารางติดตามการส่งสื่อของครูทั้ง 9 ท่าน ครบทั้ง 10 เดือนตลอดปีการศึกษา (เว้นเดือนตุลาคม)
   - สีสถานะชัดเจน: เขียว (ส่งแล้ว), แดง (ยังไม่ส่ง), เทา (ยังไม่ถึงกำหนด)
   - คลิกที่สถานะเพื่อดูผลงาน รายละเอียด และภาพถ่ายของครูท่านนั้นได้ทันที
   - สรุปตัวเลขภาพรวม: จำนวนครูที่ส่งแล้ว/ยังไม่ส่ง, จำนวนสื่อสะสม, อัตราความสำเร็จ (%)
   - สรุปสถิติแยกตามกลุ่มสาระและประเภทของสื่อ

2. **แบบฟอร์มส่งสื่อและคลังภาพถ่าย (สำหรับครูผู้สอน):**
   - กรอกข้อมูลชื่อสื่อ วัตถุประสงค์ วิธีการใช้ และผลลัพธ์ที่เกิดขึ้นกับผู้เรียน
   - แนบภาพถ่ายขณะนำสื่อไปใช้ในห้องเรียนได้สูงสุด 10 รูปต่อชิ้น
   - ระบบบีบอัดภาพอัตโนมัติบนเครื่องฝั่ง Client ก่อนอัปโหลด ประหยัดพื้นที่จัดเก็บและส่งได้รวดเร็ว
   - เลือกเดือนที่ส่งสื่อได้เฉพาะ 10 เดือนที่กำหนด (พ.ค. - ก.ย. และ พ.ย. - มี.ค.)

3. **คลังสื่อการจัดการเรียนรู้ (Gallery):**
   - แสดงการ์ดผลงานพร้อมภาพหน้าปก
   - ค้นหาและกรองตามชื่อครู, ระดับชั้น, วิชา, ประเภทสื่อ, และเดือน
   - มี Modal ขยายดูรูปภาพขนาดเต็มแบบ Lightbox

4. **ประวัติและสถานะส่วนตัว (My Submissions):**
   - ครูสามารถตรวจสอบสถานะการส่งสื่อของตนเองครบ 10 เดือน
   - จัดการ ลบ หรือตรวจสอบผลงานของตนเอง

5. **รายงานและการส่งออก (Reports & Export):**
   - ดาวน์โหลดรายงานสรุปเป็นไฟล์ **Excel (.xlsx)** อัตโนมัติ ครบถ้วนทั้งตาราง Matrix และรายการสื่อ
   - หน้ารายงานแบบพิมพ์พร้อมใช้งาน มีช่องลงชื่อผู้รายงานและผู้อำนวยการ

6. **ระบบจัดการรายชื่อครู (Teacher Management):**
   - บันทึกรายชื่อครูทั้ง 9 คน พร้อมวิชาและระดับชั้น
   - สามารถเพิ่ม แก้ไข หรือเปิด/ปิดการใช้งานรายชื่อครูได้

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS + Lucide Icons + Google Font (Sarabun & Prompt)
- **Database & Auth:** Supabase (PostgreSQL, Row Level Security, Auth)
- **Image Storage:** Supabase Storage (Bucket: `submission-images`)
- **Excel Export:** SheetJS (xlsx)
- **Deployment:** Vercel

## 🚀 วิธีการเริ่มต้นใช้งาน (Local Development)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ตั้งค่าตัวแปรสภาพแวดล้อม (Environment Variables)
คัดลอกไฟล์ `.env.example` ไปเป็น `.env.local`
```bash
cp .env.example .env.local
```
แก้ไขค่าในไฟล์ `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

### 3. รันฐานข้อมูลบน Supabase
นำคำสั่ง SQL ในไฟล์ `supabase/schema.sql` ไปรันใน **Supabase SQL Editor** เพื่อสร้างตาราง นโยบายความปลอดภัย (RLS) และข้อมูลครูเริ่มต้นทั้ง 9 ท่าน

### 4. รันโปรเจกต์ในโหมด Development
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

## 👥 รายชื่อครูในระบบเริ่มต้น (9 ท่าน)

### กลุ่มที่ 1 ครูระดับปฐมวัย
1. **ครูธารารัตน์ สามิภักดิ์** (ระดับปฐมวัย อ.1 - อ.3)
2. **ครูนภาวรรณ สันดิษฐ์** (ระดับปฐมวัย อ.1 - อ.3)

### กลุ่มที่ 2 ครูระดับประถมศึกษา
1. **ครูณิชนันทน์ การบุญ** (ประจำชั้น ป.1, สอนทุกวิชาเฉพาะชั้น ป.1)
2. **ครูกชกร อรัญวัชน์** (ประจำชั้น ป.2, ครูประจำวิชาภาษาไทย)
3. **ครูรักชนก โสภักต์** (ประจำชั้น ป.3, ครูประจำวิชาคอมพิวเตอร์ / วิทยาการคำนวณ)
4. **ครูมณีมัญช์ ศาสตร์ทรัพย์** (ประจำชั้น ป.4, ครูประจำวิชาวิทยาศาสตร์)
5. **ครูณัฐวุฒิ คำจันทร์** (ประจำชั้น ป.5, ครูประจำวิชาสุขศึกษาและพลศึกษา)
6. **ครูชมพูนุท บุญอากาศ** (ประจำชั้น ป.6, ครูประจำวิชาภาษาอังกฤษพื้นฐานและเพิ่มเติม)
7. **นางสาวจันทนิภา เขียวละลิ้ม** (ประจำชั้น ป.6, ครูประจำวิชาคณิตศาสตร์)
